# Access marks

The icons for what a person can do: read, write, append, and control.

The shape carries the meaning. Do not rely on colour alone. A row that was returned because it could be read may wear the read icon. Do not put a write icon on every row.

A vault the person can write but not read gets no icon. The two-way icon would claim a read that is not there. Put the words "Write only" beside the empty spot instead.
