# Predicate tree

Use this when a person picks how two things are related, and the list of relations is a tree.

The host loads the catalogue. This unit walks it. It does not stop at a fixed depth: if the catalogue grows a fifth level, the walk includes it. A loop in the data stops the walk instead of freezing the page.

Reading a link backwards uses only words the catalogue stored for that direction. If those words are missing, the answer is silence. It does not invent a phrase.

It does not choose which relations a person may be offered. That list comes from the catalogue the host loaded.
