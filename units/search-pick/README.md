# Search and pick

One way to search a catalogue and pick a row. Skills, places, languages, types, and people all use it. The catalogue is the host's job. This unit only decides what the person sees.

Three different sentences, and they must not be swapped:

- Keep typing, when the text is still too short to search.
- Nothing matched. That does not mean the thing is absent.
- The search failed. The catalogue was not read.

Picking a row does not create a new term. The host decides what a pick writes.
